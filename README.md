# ImageFest

ImageFest is a dynamic image discovery app designed to help users quickly find high-resolution photography based on their search inputs. Once fully implemented, users will be able to search for specific topics and view the results in a fluid, responsive gallery.

### Design Decisions
1. **Empty-State Messaging:** I included a dedicated empty-state paragraph (`#empty-state`) that remains visible while the results grid is empty, providing immediate feedback to the user on what action to take next.
2. **Category Suggestion Chips:** I added a row of clickable category chips below the search bar. This serves as a quick-start guide to inspire users who might not know what to search for immediately, enhancing the overall user experience.
